# Pokédex · Kanto

Interface atualizada para acompanhar o visual da DigiDex, com catálogo local da primeira geração, busca, filtro por tipo, fichas com descrição e atributos base, e distribuição por tipo.

## Abrir

Abra `index.html` no navegador. Os 151 registros ficam em `catalog.js` e `catalog.json`; as imagens são carregadas da coleção de sprites do PokeAPI.

## Arquivos

- `index.html`: interface navegável.
- `catalog.js` e `catalog.json`: dados locais de Kanto com 151 Pokémon.

Os dados e as descrições vieram do catálogo existente do projeto Pokédex. A interface reaproveita os valores e textos em português e acrescenta imagens de arte oficial hospedadas na coleção de sprites do PokeAPI.
